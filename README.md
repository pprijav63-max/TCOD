# TCOD SIMAP Radar

Javni dnevni pregled švicarskih javnih natječaja za Codeling d.o.o. Zagreb / THE CODE Architecture.

- Izvor: službeni javni SIMAP API (bez prijave)
- Opseg: svi švicarski kantoni, zadnjih 30 dana, s otvorenim rokovima
- Prikaz: hrvatsko sučelje i neslužbeni hrvatski sažeci
- Automatski zadatak: GitHub Actions, raspored Europe/Zurich
- Web: https://tcod-simap-radar.yapp.page/

**Status se smatra aktivnim tek nakon prve uspješne produkcijske sinkronizacije.**

Dies ist keine amtliche Veröffentlichung. Massgebend sind die auf der Plattform www.simap.ch veröffentlichten Daten.
